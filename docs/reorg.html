January vs July: what the reorg changed

MindkeeperMap.diff(jan, jul) compares two trees by node id, and highlightDiff() rings the cards: green joined, red left, amber title changed, dashed amber moved to a new manager. On the July chart the people who left are listed in the legend; switch to January to see them in place. 

const diff = MindkeeperMap.diff(january, july);
// { added: [...], removed: [...], moved: [...], changed: [...], links: { added, removed }, info: { id: { topic, from, to, fields } } }
map.init(july).highlightDiff(diff);
map.clearDiff();

mindkeeper-mcp keeps a change history with effective dates, so an assistant can answer the same question with diff_between('2026-01-31', '2026-07-31'). Data: samples-data.js.
