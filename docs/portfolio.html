People × companies × projects

A holding company with three portfolio companies, their people and projects. The tree says who belongs where; the dashed, labelled links carry everything that crosses it: an advisor on two boards, a CTO helping a sister company, one product powering another. Ended projects show as faded dashed cards. 

map.init({
  id: 'group', topic: 'Harbor Group', kind: 'company',
  children: [ /* companies, people, projects, teams */ ],
  links: [
    { from: 'pf-helen', to: 'northwind', type: 'board' },
    { from: 'atlas', to: 'routes', type: 'powers' }
  ]
});
map.addLink('pf-rhea', 'routes', 'investor');
map.getLinks();

In mindkeeper-mcp the same graph is built with add_entity and link_entities, and queried with projects_of and members_of. Data: samples-data.js.
