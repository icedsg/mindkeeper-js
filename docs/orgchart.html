A 40-person company as an org chart

Northwind Labs (made up) with layout: 'orgchart': managers sit above their reports, each card shows the name and title, and the +/- under a manager folds that branch. Leaf teams of four or more stack in a column. Drag to pan, scroll to zoom. 

const map = new MindkeeperMap('#chart', { layout: 'orgchart' });
map.init({
  id: 'maya', topic: 'Maya Chen', kind: 'person', meta: { title: 'CEO' },
  children: [
    { id: 'daniel', topic: 'Daniel Okafor', kind: 'person', meta: { title: 'CTO' }, children: [ /* ... */ ] },
    // ...
  ]
});
map.on('nodeToggle', e => console.log(e));

The data is in samples-data.js. With mindkeeper-mcp an assistant can build the same chart from a CSV (import_csv) and export it (export_orgchart).
